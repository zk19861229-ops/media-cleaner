## 浏览器用例复现

```sh
cd web
npm ci
npm run build
npx playwright install chromium
npm run test:browser
```

测试用 Playwright 路由提供本地构建内容，无需监听端口，也不上传媒体：

1. 合成样本演示、预览和计划下载，无删除入口。
2. 真实浏览器 OPFS 句柄、IndexedDB 克隆及文件操作；返回检查不删除，明确确认后只删除两个副本，保留一个。
3. 刷新后保留选择，改写合成目标后执行跳过。
4. 390 × 844 手机视口无横向溢出，设置展示发送范围并保存截图。

OPFS 用例替换了目录选择器，不能替代操作系统授权测试。可以用 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定兼容 Chromium。

## 待完成的运行验收

使用独立合成目录，首次验收不处理个人媒体。

| 检查 | 操作与预期 |
| --- | --- |
| 桌面目录 | Chrome / Edge 从 localhost 或 HTTPS 进入，选择目录，递归扫描不越界；取消授权不改文件。 |
| 删除闭环 | 三份相同图片：关闭确认弹窗不删除，明确确认后删除勾选的两份，保留一份。 |
| 视频 | 两份相同视频和一个不同大小视频：核对重复组及播放能力。 |
| 相似与保护 | 相似图默认不勾选；保护文件和截图不能成为已选择删除目标。 |
| 执行变化 | 分析后改写目标、删除保留副本、撤销写入权限：执行跳过且不计容量。 |
| 刷新与多标签 | 保存计划和选择；权限失效要求重授权；只允许一个标签页获得执行锁。 |
| 中断 | 执行中关闭页面再继续，归属不明的删除显示不确定，不报告成功释放。 |
| 手机只读 | 选择、分析、预览及导出；无目录写入 API 时不可清理原文件。 |
| 存储失败 | 禁用 IndexedDB 后降级只读，不能批准删除。 |
| 模型 | 默认不请求模型；自有测试网关联调 CORS、匿名字段、错误回退；刷新清除 token 和启用状态。 |
| 规模 | 1,000 / 10,000 个合成媒体及大视频，记录时间和内存，尚无性能结论。 |
