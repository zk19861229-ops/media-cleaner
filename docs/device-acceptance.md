# Android 设备验收

此清单不表示已完成实测。仅在新建的合成测试目录执行；不要选择个人照片目录进行首次验证。

## 准备

1. 安装 JDK 17、Android SDK 35，在项目目录运行 `./gradlew :core:test :app:assembleDebug :app:lintDebug`。
2. 用 `python3 scripts/make-fixtures.py /tmp/spacekeeper-fixtures` 生成全新测试目录（仅 Python 标准库；安装 ffmpeg 后会生成视频）。目录已存在时脚本拒绝运行。
3. 把合成目录复制到手机 `Documents/spacekeeper-fixtures`。安装 debug APK。

## 核心场景

- 首次启动不出现宽泛存储权限请求；只有点击选择目录才打开系统选择器。
- 选择本地测试目录，授权只读时提示需要读写，取消选择不改变旧目录。
- “开始分析”后遍历嵌套目录，发现图片和重复视频，忽略文本文件。
- 完全重复组至少保留一份；相似照片默认不勾选。
- 改选保留副本后，该组删除勾选清空，容量更新，需要重新选择删除对象。
- 查看每个保留项和删除项，图片可放大、视频可播放（使用系统查看器）。
- 保护一个待删除文件后，其删除勾选取消；后续扫描仍受到保护。
- 截图保护打开时，`Screenshot_protected.png` 作为保留项或被排除。
- 取消某个勾选后，数量和容量立即更新；确认前不删除任何文件。
- 确认弹窗明确“永久删除、不可恢复”；取消后文件全部存在。
- 确认执行后仅删除选中测试文件，保留副本可打开，文本和唯一文件仍存在。

## 故障与恢复

- 计划生成后改写候选文件，即便保持大小不变，也应被新哈希检查跳过。
- 计划生成后移走/改写保留副本，依赖它的删除动作跳过。
- 生成计划后撤销系统目录授权，执行不应删除文件。
- 执行中终止进程，重启后手动继续；已成功的动作不重复执行。
- 删除接口返回前进程退出，文件已不存在但无法证明归属时，结果标记不确定，不计释放容量。
- 临时卸载存储或权限异常，不能被解释成文件已不存在。
- 中途暂停分析，再开始复用有效缓存，不把部分遍历结果当成完整目录。

## 模型集成

- 默认设置不产生模型网络请求；输入文字在未连接时提示使用本地设置。
- HTTPS 网关启用前说明数据范围，令牌不以明文存储或打印。
- 根据 `model-gateway.md` 提供合法响应后，界面显示解析后的实际策略。
- Jev 返回组外 ID、未知枚举、NaN、超范围置信度、超大响应或 HTTP 错误时，转入人工复核。
- 模型关闭或失败时，完全重复清理仍然可用。

## 尚需收集的性能数据

使用经授权的 1 千、1 万媒体样本测量扫描时间、内存峰值、耗电及相似候选误报。不能用供应商通用延迟替代本应用指标。
