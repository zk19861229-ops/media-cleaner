# 拾光清理 Web

图片与视频清理应用的浏览器版本。文件在本机分析，用户查看并确认具体计划后，才允许执行删除。默认使用本地规则，LLM / Jev 通过可选 HTTPS 网关接入。

## 启动

需要 Node.js 22+。在本目录运行：

```sh
npm ci
npm run dev
```

访问 `http://127.0.0.1:4173`。`dev` 先构建再提供静态文件，修改源码后重新运行。已有构建时使用 `npm run preview`。

`npm run build` 生成完整静态站点 `dist/`，可部署到 HTTPS 静态托管服务，无需接收媒体的后端。预构建交付包 `../output/spacekeeper-web.zip` 解压后也可尝试直接打开 `index.html`；`file://` 的存储与 Worker 支持因浏览器而异，建议仅用于只读预览，完整目录流程使用 HTTPS 或 localhost。手机访问电脑的普通 HTTP 局域网地址不属于安全上下文。

## 浏览器能力

| 环境 | 本地分析与预览 | 清理原文件 |
| --- | --- | --- |
| 新版桌面 Chrome / Edge，HTTPS 或 localhost | 目录授权、递归扫描 | 需要写入权限、IndexedDB、Web Locks；确认计划后永久删除 |
| 不提供目录写入 API 的浏览器，包括通常的手机浏览器 | 选择媒体或浏览器支持的目录、分析、导出 JSON | 不支持，页面为只读模式 |
| 本地记录不可用 / 隐私模式限制 | 尽可能提供内存中的分析与导出 | 禁用 |

应用按能力检测决定模式。Web 版不能绕过手机系统权限或访问其他应用私有目录。HEIC、MOV 等格式可能可做完整哈希去重，但预览和图像特征提取取决于浏览器解码支持。

## 操作流程

1. 可先点击「体验演示」，使用页面生成的六张合成图片；演示模式不可删除原文件。
2. 选择文件夹或媒体，设定是否查找相似照片、保护截图。
3. 点击「分析并生成计划」。完全重复文件通过完整 SHA-256 分组；相似照片使用 dHash 与清晰度指标提示，默认不勾选删除。
4. 预览图片或视频，逐项勾选、改选保留副本、整组保留或保护文件。
5. 写入模式点击「查看并确认清理」，检查数量和永久删除说明后确认；只读模式导出计划，需自行在系统文件管理器处理。
6. 在历史查看成功、跳过及不确定结果。已确认但中断的任务可继续，不确定删除不计入释放容量。

没有回收站。释放量是成功删除文件的逻辑大小，不是设备剩余空间的精确增量。首次验收请使用独立合成目录。

## 架构

```text
用户偏好 → LLM 网关 → 受限策略（相似筛选、截图保护）
授权目录 → 本地 Worker → SHA-256 / 图像特征 → Ontology 对象与证据
相似组匿名特征 → Jev 网关 / 本地规则 → 保留项建议
Ontology 约束 → 可编辑清理计划 → 用户确认 → 确定性执行器
                                              ↓
                         权限、保护、内容、保留副本复核 → 日志与删除
```

- `src/ontology.mjs`：媒体、证据、分组、动作、计划、确认摘要及执行状态机。完全重复组不再参加相似分组，避免保留项依赖链。
- `src/files.mjs`、`src/analysis-worker.mjs`：目录范围、遍历、分块哈希、图像特征和缓存。哈希按 1 MiB 分块，图片解码仍可能占用较大内存。
- `src/storage.mjs`：IndexedDB 保存目录句柄、元数据、保护、计划、确认与执行日志。版本检查拒绝过期编辑，Web Locks 防止本站多个标签页同时执行清理。
- `src/gateway.mjs`：自定义 LLM / Jev 接口，严格校验结构、超时与响应大小；连续失败转人工复核。没有伪造的模型置信度。
- `src/app.mjs`、`src/view.mjs`：概览、计划、预览、历史、设置及响应式界面。

确认绑定计划版本及完整内容摘要。删除前重读目标和保留文件，再次检查权限、保护及目标快照；删除前日志必须持久化。浏览器 API 没有跨应用的原子「检查并删除」操作，不能阻止其他应用在最后检查后改写文件，使用时避免同步修改同一目录。

## 隐私与模型

默认无媒体上传、无统计 SDK、无外部图片或字体。远程模型仅接收用户主动输入的偏好或匿名成员 ID、尺寸、清晰度与保护标记，不发送媒体、文件名、路径或完整哈希。

密钥仅留在当前页面内存，刷新清除；远程启用状态也会关闭。网关 URL 和策略可以持久保存。网关需允许站点来源的 CORS，详见 [网关契约](../docs/model-gateway.md)。这不是官方 Jev SDK，尚未完成真实模型联调。

本地记录包含文件名、路径及计划，不是加密保险箱。「忘记目录」仅移除连接，历史计划仍保留；清空浏览器本站点数据才能移除全部本地记录。导出 JSON 同样包含文件路径，分享前请检查。

```sh
npm run check
npm test
npm run build
npx playwright install chromium
npm run test:browser
```

**74 项 Node 测试及静态构建通过。** 浏览器用例已编写，但当前环境在 Chromium 启动阶段失败，未完成界面、真实 IndexedDB / OPFS、系统目录授权及移动浏览器验收。详见 [Web 验证记录](../docs/web-verification.md)。

本版不包含视频压缩、视频画面相似分析、后台定时扫描、云盘、回收站或 PWA 离线缓存。万级媒体的耗时、内存和电量尚未测量。扫描时保持页面打开；只读选择刷新后需重新选择，目录句柄也可能需要重新授权。
